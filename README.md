# Generador de Números Aleatorios con Distribución Normal

Proyecto desarrollado en Python para generar números pseudoaleatorios utilizando semillas configurables y el Teorema Central del Límite.

## Funcionalidades

- Generación de números pseudoaleatorios.
- Uso de semillas para reproducibilidad.
- Aproximación a una distribución normal.
- Análisis estadístico de resultados.

## Tecnologías

- Python
- Estadística
- Simulación Computacional
